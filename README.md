## 🛠️ Run Locally

### Prerequisites
Node.js v18+ must be installed:
https://nodejs.org

```bash
# 1. Clone the repo
git clone https://github.com/Ameera-06/SpendWise.git

# 2. Enter the folder
cd SpendWise

# 3. Install dependencies
npm install

# 4. Start the app
npm run dev
```

## Deployment
